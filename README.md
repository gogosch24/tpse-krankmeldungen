# Krankmeldungen-Tool

Download the latest version for your operating system from the **Releases** section on the right:
- `KrankmeldungenTool-Windows.zip` for Windows
- `KrankmeldungenTool-Mac.zip` for macOS

You do not need to install Java separately.

## Windows
1. Extract the ZIP file.
2. Open the extracted folder and double-click `KrankmeldungenTool.exe`.

## macOS
1. Double-click the ZIP file to extract `KrankmeldungenTool.app`.
2. Double-click `KrankmeldungenTool.app` to open it.

Note: macOS might block the app on the first launch because it is not signed. If that happens, open **System Settings -> Privacy & Security**, scroll down, and click **Open Anyway**.
